---
title: First run
description: What to do the first time Builder Launcher opens.
---

![Home after install: clock, weather, todos, command bar at the bottom](../../../assets/screenshots/home.png)

1. **Allow contacts** if you want `@` and `#` to complete names. The launcher asks on first open, together with **calendar** for the next event under the clock. If you skip calendar, grant it later from settings → **… calendar >**.
2. **Become Home** when Android offers. You can skip and do it later from settings.
3. Type `settings`. Set a weather city (type a name, pick a match — no GPS required) and metric or imperial units.
4. **Type `help`** or tap the `>` prompt to see commands.
5. Optional: grant **notification access** so the hub fills with messages and calendar alerts.
6. Optional: pick an AI provider before you use `?`. Nothing is sent until you ask.

The command bar always sits at the bottom. On a slab phone the software keyboard stays open. On a hardware QWERTY (auto or hardware mode) it stays out of the way.
