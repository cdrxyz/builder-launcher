---
title: Keyboard
description: Auto, hardware, or software. Command bar stays at the bottom.
---

Keyboard mode in settings: `auto` (default), `hardware`, or `software`.

| Mode | Behavior |
| --- | --- |
| auto | Treats a hardware QWERTY as present (Titan 2 Elite and most BlackBerry-style Androids). |
| hardware | Always hide the software keyboard; bar sits above the physical keys. |
| software | Slab phone. Bar sits just above the IME. |

The command bar always sits at the bottom. D-pad right from the bar opens the hub. Enter submits.
