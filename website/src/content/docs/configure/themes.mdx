Type `settings` and pick a theme, then `dark` or `light`. Screens stay the same; type, color, lists, charts, and the command bar change.

| Theme | What you get |
| --- | --- |
| `cyberpunk` | Terminal UI. Monospace, green on black (or cream paper in light). Underline command bar. |
| `plain` | Black and white. Rounded accent outline on the command bar, list rows, and badges. |
| `material` | Material surfaces. Filled cards, chips, left-aligned titles, rounded chart bars. |
| `ios` | Large title, grouped lists, segmented period control. |

Each theme has both `dark` and `light`. Default is dark for cyberpunk and plain, light for material and ios. Picking a theme or tone also sets its default accent. You can still pick another color in [settings](settings/).
